# Experiment and data provenance

Personal research project of Kai Chi, dated 22 October 2026.

## What is measured and what is derived

The numerical records were generated by executing the supplied Python code in
the supplied environment. Source hashes, versions, thresholds, seeds, raw
timings, reference misses and instance arrays are retained. Analytical propositions have
written proofs and numerical checks; priority and independent expert review
remain outstanding. Numerical checks do not establish originality, interval
arithmetic guarantees or journal suitability.

The core benchmark settings were fixed before the main execution. This is not
an externally preregistered experiment. Development used a separate Abilene
100-flow smoke test, seed 7. A finite-anchor theoretical extension was derived
while the main execution was running, before inspecting comparative results.
It does not change or replace any measured method, case or threshold. The
manuscript distinguishes analytical guarantees, numerical validation and
empirical conclusions.
The shifted alpha-fair extension, two-by-two certificate ablation and
stratified runtime analyses were likewise specified during execution before
comparative outcomes were inspected. They supplement the original fixed
log-utility benchmark rather than replacing it.

The original execution ended after 154 complete anchors, 596 capacity cases
and 7,152 timing records. Its checkpoint was preserved before resuming the
last two scaling anchors in a later process. All earlier timing values were
retained. Full original wall time is unavailable. The supplied resume driver
changes only checkpoint restoration, completed-anchor skipping and elapsed-
time reporting, and retains the original benchmark and solver source hashes.

The execution hashes remain unchanged. Source headers and status descriptions
were later revised; `results/source_text_revision.json` records both versions'
hashes and their matching numerical AST fingerprints. Only module prose and
status-description strings are excluded from that comparison. Mathematical
operations, numerical constants, settings and saved observations are unchanged.

## Public data and third-party attribution

Six unmodified GraphML source files and the exact licence are included from
Matthew Roughan's InternetTopologyZoo repository, pinned to commit
51118849b99534f01010d885d66321433a7eef9e. The source manifest records exact
URLs, hashes and retrieval dates. The repository states Creative Commons
Attribution 4.0 International; see `data/InternetTopologyZoo/LICENSE`.

Attribution: S. Knight, H. X. Nguyen, N. Falkner, R. Bowden and M. Roughan,
*The Internet Topology Zoo*, IEEE Journal on Selected Areas in Communications,
29(9), 1765-1775, 2011. https://doi.org/10.1109/JSAC.2011.111002 .
Source: https://github.com/mroughan/InternetTopologyZoo .

Only topology structure is used. Parsing converts graphs to simple undirected
graphs, drops self loops, retains the largest component, expands edges to
directed links, selects deterministic shortest paths and drops unused links.
The preprocessing summary is in `results/topologies.json`. Capacities, utility
weights, session endpoints and capacity shocks are generated; they are not
observed operator data. No external publication's figures, code or full text
are redistributed in the package. Bibliographic references are supplied in
the manuscript and `RELATED_WORK.md`.

## Scope of responsibility

The package does not establish a first-in-literature result or Q1 readiness.
Current GPU and packing-method publications are related work, not reproduced
competitive baselines. Their reported wall-clock times must not be compared
with these CPU measurements as if the workloads and machines matched. The
six topology families are convenience selections, not a representative random
sample of deployed networks. Three timing repetitions per case measure
execution noise and do not multiply the independent sample size.

Independent review and further work are needed before external submission.

## Document format

The DOCX prose, tables and display equations are editable. Equations use
native Word math converted by Pandoc; chart PDFs are vector exports. The PDF is rendered from the same
DOCX and checked page by page. Source, result and data files can be used to
recompute the displayed numerical evidence independently.
